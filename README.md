# NextGen-Networker
In today’s digitally connected world, social media platforms have become an integral part of our lives, allowing us to connect, communicate, and share content with others. NextGen Networker presents a comprehensive overview of a web-based social media application project that aims to provide a seamless user experience, prioritize privacy and security, and incorporate modern design elements. 
The platform will allow users to create and manage their profiles, communicate, and share content with others. It provides a user-friendly interface that allows individuals to create profiles, post updates, upload media, interact with other users, and discover new content. 

# Software-Requirements
* Visual Studio code
* xampp (for database)
